1. ARSITEKTUR SISTEM SAAT INI
================================================================================

- Framework    : Flask (Python)
- Server       : Waitress (port 80, 16 threads)
- Database     : Microsoft SQL Server (192.17.17.201\SQLSERVER)
- DB Name      : tct_inventory
- Auth         : JWT token disimpan di cookie "token"
- Auth Module  : app/auth.py (TERENKRIPSI PyArmor - TIDAK BISA DIMODIFIKASI)
- Secret Key   : "secret-keyku2023Lutfi" (file config/secretKey.py)
- Frontend     : AdminLTE + Bootstrap 4 + jQuery + DataTables
- Realtime     : Flask-SocketIO (polling mode)

Alur autentikasi:
  1. User login via auth.py (PyArmor) → JWT token dibuat
  2. Token disimpan di cookie "token"
  3. Setiap route membaca cookie, decode JWT dgn jwt.decode()
  4. Payload JWT berisi: sub (username), nama_lengkap, level_user
  5. level_user dicek secara hardcoded di route/template/JS

dbo.users HARUS tetap ada dan terisi. Sistem RBAC baru kita berjalan

8. SKEMA DATABASE
================================================================================

--- Tabel Lama ---

dbo.users
  - User_ID     INT (PK, identity)
  - Nama         VARCHAR
  - Username     VARCHAR
  - Password     VARCHAR (MD5 hash)
  - Level_User   INT (1, 2, 3, 11, 12, 13)
  - Email        VARCHAR
  - Log          VARCHAR (20 chars = sedang login / online)
  - Role_ID      INT (FK → dbo.roles) [BARU DITAMBAHKAN]

--- Tabel Baru (RBAC Dinamis, sudah dibuat) ---

dbo.roles
  - Role_ID      INT (PK, identity)
  - Role_Name    VARCHAR(50) UNIQUE
  - Description  VARCHAR(255)

dbo.permissions
  - Permission_ID   INT (PK, identity)
  - Permission_Code VARCHAR(50) UNIQUE
  - Permission_Name VARCHAR(100)
  - Module          VARCHAR(50)

dbo.role_permissions
  - Role_ID        INT (FK → dbo.roles, ON DELETE CASCADE)
  - Permission_ID  INT (FK → dbo.permissions, ON DELETE CASCADE)
  - PRIMARY KEY (Role_ID, Permission_ID)

--- Data Permission yang sudah dimasukkan ---

  Permission_Code       | Permission_Name                              | Module
  ----------------------|----------------------------------------------|--------
  USER_CRUD             | CRUD Pengguna (Tambah, Edit, Hapus User)     | Settings
  ROLE_MANAGE           | Mengelola Peran & Izin Akses                 | Settings
  WH_MASTER_EDIT_FULL   | Edit penuh data master barang                | Gudang
  WH_MASTER_EDIT_PARTIAL| Edit terbatas master barang (Jenis & Racking)| Gudang
  WH_DELETE_BON         | Hapus dokumen Bon masuk/keluar utuh          | Gudang
  WH_VIEW_PRICING       | Melihat kolom CURRENCY & PRICE               | Gudang
  PMC_DELETE            | Menghapus data transaksi PMC                 | PMC
  PMC_EDIT_RETURNS      | Memperbarui kolom pengembalian barang PMC     | PMC
  IT_MANAGE             | Menyetujui, mengedit, menghapus form IT/Void | IT

--- Pemetaan Izin Awal ---

  SuperAdmin (1)    → SEMUA izin
  User (2)          → PMC_DELETE
  Order Viewer (3)  → WH_VIEW_PRICING
  SPV Gudang (11)   → WH_MASTER_EDIT_FULL, WH_VIEW_PRICING
  Admin Gudang (12) → WH_MASTER_EDIT_PARTIAL
  Operator Gudang (13) → (tidak ada izin khusus)
