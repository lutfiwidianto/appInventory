Keamanan Master Admin (lutfi)

Bypass Mutlak: User lutfi memiliki hak akses khusus di tingkat inti aplikasi sehingga tidak akan pernah terkunci meskipun lisensi dimatikan, diganti di GitHub, atau masa berlaku habis.

Proteksi Menu: Halaman pengaturan dan endpoint API ini terenkripsi dan diverifikasi oleh token JWT. User lain yang mencoba mengakses URL ini akan langsung ditolak dengan kode 403 Forbidden.

Kill-Switch Instan: Begitu kunci lisensi diubah atau proteksi dimatikan dari halaman ini, efeknya langsung berlaku dalam hitungan milidetik untuk seluruh pengguna aktif.
